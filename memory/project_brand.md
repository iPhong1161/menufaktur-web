**Colors:**
- Wine Red: #7E1423 (primary background, hero sections)
- Light Beige: #FFFCE1 (primary text on Wine Red, content section backgrounds)
- Gold Yellow: #F15A22 (accent, CTA highlight)
- Garnet Red: #A72335 (secondary)
- Dark text: #2A2A2A

**Typography:** Roboto family (Google Fonts)
- H1/H2: Roboto Bold
- H3/sub-headings: Roboto Regular
- Body: Roboto Condensed Light (test legibility at small sizes; Roboto Regular is safe fallback)
- Buttons/CTAs: Roboto Bold

**Tone:** Calm, confident, warmly professional. German formal "Sie". No hype words, no excessive exclamation marks.

**Logo (web):**
- Header: horizontal logo, Light Beige on Wine Red background
- Min height: 30px (digital), recommended 40–60px desktop / 32–40px mobile
- Favicon: logo mark (chef's hat icon) only, on Wine Red background
- Logo files to source from designer: SVG variants in /assets/logos/

**Extended palette note:** Some extended palette HEX/RGB values in the brand book don't match — treat HEX as authoritative. Safest approach: Wine Red + Light Beige + occasional Gold Yellow only, until designer confirms the rest.

**Why:** Authoritative brand from BRAND_GUIDE.md and LOGO_USAGE.md.
**How to apply:** Use these colors/fonts faithfully. Match Stitch prototype visual style. Never use hype microcopy.
